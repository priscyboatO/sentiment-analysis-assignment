# Amazon Alexa Sentiment Analysis

## Project Overview
This project performs sentiment analysis on Amazon Alexa customer reviews using traditional machine learning and BERT-based text classification.

## Dataset
The project uses the publicly available Amazon Alexa Reviews dataset. The main variables used are customer reviews and sentiment feedback.

## Methods
- Text cleaning and preprocessing
- Bag of Words
- TF-IDF
- Word2Vec embeddings
- PCA visualization
- Logistic Regression
- Support Vector Machine (SVM)
- GridSearchCV for parameter tuning
- DistilBERT fine-tuning
- Model evaluation using Accuracy, Precision, Recall, F1-Score, and ROC-AUC

## Visualizations
The notebook includes:
- Sentiment distribution
- Word embedding PCA visualization
- Confusion matrices
- ROC curves
- Model performance comparison
- Feature importance

## How to Run
1. Open the notebook in Google Colab.
2. Select a GPU runtime for the BERT section.
3. Run all cells from top to bottom.
4. Review the model evaluation results and visualizations.
